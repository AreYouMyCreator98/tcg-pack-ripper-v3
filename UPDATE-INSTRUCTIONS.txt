BROKEN BINDER CARD DELETE PATCH
================================
1. Extract this ZIP.
2. Copy the CONTENTS into the root of tcg-pack-ripper-v3.
3. Replace existing files when Windows asks.
4. GitHub Desktop -> commit -> Push origin.

What changes:
- Failed Binder artwork tiles now have TRY AGAIN and REMOVE.
- Binder artwork status gets REMOVE BROKEN for all currently-known low-res artwork failures.
- REMOVE permanently deletes the owned Binder entry/all copies from the save.
- Master Set progress and collection value will drop accordingly.
- Healthy cards and high-res-only failures are not targeted.
